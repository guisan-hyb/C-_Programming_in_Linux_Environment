# 09 · 附：两张图的文字内容（对照用）

两张 PNG 里嵌着 drawio 的原始图表 XML（`C++改造架构.drawio.png`、`C++改造类图.drawio.png`），
所以图上的每个文字框都能被精确取出来。这一章把图上写的内容抄成文字，并标出对应的代码位置 —— 读图时对着它看，比盯着图猜快得多。

**一个重要结论：这两张图和当前代码是一一对应的，没有任何"图上有、代码里没有"的东西。**
也就是说它们是**现状文档**，描述的正是这份已经改造成 C++ 的代码，而不是一张"还没实现的目标图"。

**图上看不出来、但代码里很重要的三个细节**（图上只画了 happy path）：

1. 收数据是 **"循环读到 EAGAIN"**，不是"读一次"（ET 模式的硬要求）；
2. 发送遇 `EAGAIN` 后，**已发出的偏移 `_offset` 被保留**，下次从断点续写；
3. 队列发空后要把 **EPOLLOUT 摘掉**，图里没有体现这一步。

## 4. 怎么自己把图里的文字抠出来（万一以后图更新了）

drawio 导出的 PNG（带 `-drawio` 后缀的那种）会把图表 XML 塞进 PNG 的 `tEXt` 块里，且是 URL 编码过的。用 20 行 Python 就能读：

```python
import struct, urllib.parse, re, html
data = open("C++改造架构.drawio.png", "rb").read()
i = 8
while i + 8 <= len(data):
    ln = struct.unpack(">I", data[i:i+4])[0]          # 块长度
    typ = data[i+4:i+8]                                # 块类型
    if typ == b"tEXt":
        kw, _, text = data[i+8:i+8+ln].partition(b"\x00")
        xml = urllib.parse.unquote(text.decode("utf-8"))
        for c in re.findall(r"<mxCell\b[^>]*>", xml):
            m = re.search(r'value="(.*?)"', c, re.S)
            if m:
                v = html.unescape(m.group(1))
                v = re.sub(r"<[^>]+>", " ", v).strip()
                if v: print("-", v)
        break
    i += 12 + ln
```
